## ✨ Overview

**Vitra** brings a fresh visual identity to Spotify on iOS.

Inspired by Apple's Liquid Glass design language, Vitra explores transparency, depth, blur and fluid visual elements to create a more immersive music experience.

Not just another Spotify customization.

**A different way to experience music.**

## 🧊 Features

| Feature | Description |
|---|---|
| Liquid Glass | Glass-inspired interface |
| Dynamic Blur | Modern translucent surfaces |
| Fluid UI | Refined visual transitions |
| iOS Integration | Design inspired by iOS 26 |
| Customization | Experimental interface enhancements |

*Features are subject to development and compatibility.*

## 📱 Compatibility

| Component | Support |
|---|---|
| iOS | 26+ |
| Spotify | 9.1.78 (upstream baseline) |
| Language | Objective-C |
| Build system | Theos |

## 🛠 Development

Vitra is an experimental iOS customization project.

Development focuses on exploring interface customization, Objective-C and modern iOS design concepts.
